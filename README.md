**Archistry** is an AI-agent skill for Salesforce architects, business analysts and consultants.
Describe a diagram in plain language and get an editable **draw.io** file, an interactive **HTML**
page and **PNG / JPG / SVG** images, laid out and checked by a deterministic engine.

| 🔎 Discover | 🏛️ Architect | 🎨 Design | 🤖 Agentforce | 🛠️ Build · 🧪 Test · 🚢 Release |
|:---:|:---:|:---:|:---:|:---:|
| Stakeholder maps, RACI, swimlanes, journeys | Solution & integration architecture, ERD, Data Cloud, sharing | Lifecycles, flowcharts, wireframes | Agent Interaction Map & Instruction Diagram | Environments, CI/CD, test strategy, cutover |
